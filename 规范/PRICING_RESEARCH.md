# Shotviva v1 定价调研与建议

> 核查时间：2026-11-04 至 11-05（美国口径、美元价）。所有竞品数字来自各家公开定价页，未登录、未付款。标「未核实」的是拿不到一手数据的项。
> 本文只是建议，定稿后应把唯一价格表写进 ARCHITECTURE §6.2 和 `site.config.ts`，替换建站规格 G3 里的「$9.9/月」、ARCHITECTURE 的「1/3/12 个月」和 DESIGN 付费墙的「积分包 + 1 个月 + 12 个月」三套口径。

## 一、结论先说

1. **推荐方案 A（两个 SKU，全部一次性付款）**：30 天通行证 **$9.90 / 30 张**，菜单包 **$29.90 / 120 张、12 个月有效**。免费 3 张、公开、下载带小水印；付费作品默认私密、无水印、可商用。
2. 按「每张图都用 high 质量、全部额度用完、走 Stripe Managed Payments」这个最坏情况算，每张毛利 $0.18（通行证，54%）和 $0.11（菜单包，44%）。按半数额度用掉算，毛利率是 72% 和 69%。
3. 和最接近的垂直竞品 FoodShot 比（$15/月 25 张，每张 $0.60；年付每张最低 $0.24），我们每张 $0.33 / $0.25，**单价不高于它，又不要订阅**，这是 v1 的主要卖点。
4. 最需要盯的风险不是单张毛利，而是**免费 3 张的成本**：high 质量下每个注册用户约 $0.36，只卖 $9.90 通行证的话，注册到付费的转化率要到约 6% 才打平。两个缓解办法见第五节。
5. 12 个月会员、3 个月会员、自动续费：v1 都不做。

### 从表里读出来的四件事

- **餐饮垂直赛道上真正的对手只有 FoodShot**，它强制订阅、网页上不给免费试用。「免费 3 张 + 不订阅、一次性买」正好打它这两个空档。
- **美国市场对「每张 $0.25～$0.60」已经习惯**：FoodShot 月付每张 $0.40～$0.60，PosterMyWall 每次改图 $0.24～$0.38。定在 $0.25～$0.33 不算贵，也没必要去和 Lovart（每张几美分、要自己写提示词）拼价格。
- **大家都在用「积分不结转」赚未用完的额度**（FoodShot、PosterMyWall、Lovart 都是月底清零）。我们的 30 天通行证是同一个机制，只是不自动续费。
- **一次性积分包「永不过期」是常态**（PosterMyWall、image-to-image.ai）。我们的菜单包给 12 个月，比永不过期少一点承诺，但比月清零宽松很多，也方便以后做到期提醒。

## 三、单张成本估算

### 3.1 OpenAI GPT-Image-2.5 官方价格

来源：https://developers.openai.com/api/docs/pricing 和 https://developers.openai.com/api/docs/guides/image-generation （2026-11-05 查）

- 两个型号：**gpt-image-2.5-sunburst**（官方说法：编辑精度最重要时用）和 **gpt-image-2.5-flare**（快、日常高质量生成）。**两者 token 单价一样**：图像输入 $8 / 百万，缓存图像输入 $2 / 百万，**图像输出 $30 / 百万**，文本输入 $5 / 百万，缓存文本输入 $1.25 / 百万。
- 质量档有 low / medium / high / xhigh / max 五档。官方说同一质量下两个型号的 token 数可能不同，但计算器只给了一套数字。
- 缓存输入价**只适用于 Responses API 里的生图工具**，直接调 `/v1/images/edits` 不打折。

官方计算器读出来的**输出部分**成本（每张）：

| 质量 | 1024×1024 输出 token | 1024×1024 输出成本 | 1536×1024 输出 token | 1536×1024 输出成本 |
|---|---|---|---|---|
| low | 196 | $0.0059 | 158 | $0.0047 |
| medium | 439 | $0.0132 | 343 | $0.0103 |
| high | 1,756 | $0.0527 | 1,372 | $0.0412 |
| xhigh | 3,122 | $0.0937 | 2,459 | $0.0738 |
| max | 7,024 | $0.2107 | 5,488 | $0.1646 |

（计算器显示 1536×1024 比 1024×1024 用的 token 还少，这是官方计算器的原样数字，上线前用真实请求的 `usage` 复核。）

### 3.2 一次「改图」的完整成本

Shotviva 每次是「上传一张菜品照 + 模板提示词 → 出一张图」，所以还要加两样输入：

- **文本提示词**：模板提示词按约 1,000 token 估，约 $0.005。
- **输入图片**：**官方没有公布 2.5 的图片输入 token 算法**（视觉文档只说 GPT Image 系列另算，旧的 gpt-image-1 规则已随模型下线）。GPT Image 2 系列按高保真处理输入图，按 1,500～6,500 token 估，即 **$0.012～$0.052**。这是本文最大的不确定项。

| 质量 | 1024×1024 每次合计 | 1536×1024 每次合计 |
|---|---|---|
| medium | $0.030～$0.070 | $0.027～$0.067 |
| high | $0.070～$0.110 | $0.058～$0.098 |
| xhigh | $0.111～$0.151 | $0.091～$0.131 |

### 3.3 额外开销

| 项目 | 估算 | 依据 |
|---|---|---|
| 失败重试 / 退积分 | API 成本 +10% | 接口报错或被审核拦截时给用户退积分，但 OpenAI 那边可能已经收了输入费。用户自己点「重新生成」扣用户积分，不算这里 |
| 存储（R2） | 每张 < $0.001 | 原图约 3 MB + 成品约 2 MB，R2 存储 $0.015/GB·月，出流量免费；按保留期删除后可以忽略 |
| 支付手续费 | 每单 2.9% + $0.30；国际卡再 +1.5%；需要换汇再 +1%；如果用 Stripe Managed Payments（代算代缴销售税）再 +3.5% | https://stripe.com/pricing 、https://stripe.com/pricing/local-payment-methods （支付宝、微信支付同为 2.9% + $0.30）。**Waffo 费率未核实** |
| 固定成本（Vercel、Supabase、域名、邮件） | 不摊进单张 | 属于固定运营成本，验证期另算 |

**定价时用的计划成本**（已含 +10% 失败开销，向上取整）：

- **high 质量：每张 $0.12**（推荐 v1 默认用这一档，菜品质感是卖点）
- medium 质量：每张 $0.07（作为后面降本的选项，要先用真实菜品图比对效果）

支付手续费不摊进单张成本，在下面每个方案里按订单单独扣。$0.30 的固定部分对小额订单影响很大：$4.90 的单子手续费占 9%～12%，$29.90 的单子只占 4%～7%。

## 四、v1 定价方案

三个方案共用的规则（Owner 已定或本文建议）：

- 只收一次性付款：Stripe（卡、支付宝、微信支付）为主，Waffo 并行（Waffo 不支持微信支付，付款页上要按通道隐藏微信按钮）。
- 「会员」= 一次性买断一段时间，到期不自动续费。
- 1 积分 = 1 张标准图（1024×1024 或 1536×1024，high 质量）。以后要出 2K/4K 或 xhigh，在模板里写更高的消耗积分，不改价格表。
- **免费 3 张**：注册即送，作品公开展示在创作库；「重新生成」也算一张。建议免费作品下载时右下角带小水印「Made with Shotviva」（Owner 待定，见第六节）。
- **付费作品默认私密**、无水印、可商用。**通行证到期后，付费期间做的作品继续私密**，不因到期自动公开（否则商家会担心菜单图被公开）。
- 积分发放、扣减、退回仍走 ARCHITECTURE §6.1 的 SQL 函数。

为什么推荐这个：

- **$9.90 这个数已经写进建站规格和 SEO 文案**，保留它，只把「$9.9/月」改成「$9.90 for 30 days, one-time, no auto-renew」，SEO 侧改动最小。
- 两个 SKU 对应两种真实需求：通行证是「这个月做几张特价菜、社媒图」，菜单包是「一次把整本菜单拍完」，后者正好替代请摄影师，和 `/commercial-photography` 页的成本对比表能对上。
- 和 FoodShot 比：$9.90 拿 30 张，比 FoodShot Starter 月付（$15 / 25 张）便宜而且不订阅；菜单包每张 $0.249，和 FoodShot 年付 Business（$0.27）、Scale（$0.24）同一水平，但不用先交一年钱。
- 两个 SKU 的价格差 3 倍、张数差 4 倍，付费墙上一眼能看出大包更划算，可以同时测出「愿不愿意付钱」和「愿不愿意多付」两个信号。

### 备选 B：只有一个 SKU

| SKU | 价格 | 内容 | 每张单价 | 每张毛利（用满、加 MP） | 整单毛利率（用满 / 用一半） |

- 缺点：测不出「要不要大包」；做整本菜单的商家得买好几次，每次多付 $0.30 手续费，体验也差。

### 备选 C：低门槛尝鲜包 + 大一点的通行证

| SKU | 价格 | 内容 | 每张单价 | 每张毛利（用满、加 MP） | 整单毛利率（用满 / 用一半） |

### 不推荐的做法

- **12 个月会员、3 个月会员**：一次性收一年的钱，在没有留存数据的 MVP 阶段没法判断给多少张合适，还会带来长期的退款和客服问题。等有 50 个以上付费用户、知道复购率后再加。
- **「会员期内不限量」**：high 质量每张成本约 $0.12，一个重度用户一个月出 300 张就是 $36，会直接亏。Lovart 敢送不限量是因为它走「慢速排队」并有大规模算力，我们没有。
- **自动续费**：Owner 已定 v1 不做，和竞品比反而是卖点（「No subscription」可以直接写进首页直答块）。

## 五、免费 3 张的成本：最需要盯的数字

每个注册用户免费出 3 张：high 质量约 **$0.36**，medium 约 $0.21。按「免费成本 = 付费用户带来的毛利」算打平转化率（注册 → 付费）：

| 卖的 SKU | high 质量打平转化率 | medium 质量打平转化率 |
|---|---|---|
| 30-Day Pass $9.90 | 约 6.3% | 约 3.0% |
| Menu Pack $29.90 | 约 2.6% | 约 1.1% |
| Starter Pack $4.90（方案 C） | 约 11.2% | 约 5.7% |

（假设付费额度全部用完，属于偏保守算法。）

工具类产品注册到付费常见在 2%～5%，所以**只卖 $9.90 时免费额度很可能吃掉大部分毛利**。这也是推荐方案 A 带 $29.90 菜单包的原因之一。另有两个缓解办法，按影响从大到小：

1. **防刷**：注册要邮箱验证 + hCaptcha（ARCHITECTURE §7 已有），同一设备 / IP 限领一次免费额度。刷号是免费额度真正的成本来源。
2. **免费张数里含重试**：上面已写「重新生成」也算一张，避免一个免费用户实际出十几张。

不建议把免费档降成 medium 质量，第一印象是转化的关键，免费出的图就要是最好的样子。

## 六、需要 Owner 拍板的点

1. 选方案 A / B / C（推荐 A）。
2. 免费作品下载是否带水印（推荐带小水印）。依据：PosterMyWall 把去水印放在付费档；Lovart 自称免费无水印。我们免费作品本来就公开，水印 + 公开是两个付费理由。
3. 是否用 Stripe Managed Payments：多收 3.5%，换来 Stripe 代算代缴美国销售税。上面的毛利已按「用」计算。
