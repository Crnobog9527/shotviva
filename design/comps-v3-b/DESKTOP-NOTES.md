# Shotviva「暗房」桌面稿说明（comps-v3-b，2026-11-06）

给总控写进 `规范/DESIGN.md` §8.6 用。桌面是手机布局的放宽：同一套变量、字号、圆角、材质和组件，只改布局和密度；没有新颜色、新字体、新组件样式。对照板：`comps-v3-b/desktop-board.html`；截图：`design/.impeccable/review/v3b-desktop/`。

## 桌面布局决定

- **断点两个**：`md` = 768px，`lg` = 1024px。768 以下完全是手机稿（375 基线不变）。
- **左右边距**：375 为 16px，≥768 为 32px，≥1024 为 40px（`--gutter`）。
- **内容最宽 1120px 居中**（`--content`，工具类 `.w`）。1280 两侧各留 80，1440 两侧各留 160；1280 和 1440 不换布局，只差留白。应用页不再是 720px 居中——Create / Photos 的网格和工作台两列都需要 1120。
- **导航**：
  - 营销页（首页、定价）顶栏不变：字标 + 「AI photo studio」+ 幽灵 Log in。不加任何手机没有的链接。
  - 应用页 ≥768：底部 tab bar 变成**固定顶栏**（56px，上盖模糊黑），四个链接 Create / Wishlist / Photos / Account 左对齐，当前项骨白字 + 安全灯图标 + 6% 骨白底的胶囊；Photos 角标跟在文字后。余额胶囊留在页标题行右侧。没有侧栏、汉堡、面包屑。
  - 流程页（工作台）保留手机的返回栏（返回 Create 左，余额右），桌面高度 60px。
- **弹层**：≥768 所有底部抽屉变**居中对话框**：22px 圆角，1px 骨白内描边，Sheet 级投影向下，打开动画 scale .98→1 + 淡入 250ms；无抓手，不可下拉关闭（JS 在 ≥768 关闭拖拽）；关闭按钮右上 44px。宽度按用途：注册 440px、模板预览 880px（左对比图，右标题 / 价格条 / CTA 两栏）、付费墙 920px。高度上限 `100dvh - 64px`，内部滚动。
- **首页首屏（≥1024）三栏**：`minmax(0,1fr) 360px minmax(0,1fr)`，列间 32px。左：H1（一整行衬线，关键词「Image to Image AI:」包含在 H1 里，桌面 36px）、副题、逐字回答；中：生成器卡（4:5 取景框 + 快门，桌面上井里不放示意图，只有取景角标和「Add your phone photo」）；右：同一张 Pure White 前后对比滑块（4:5，Phone / AI 标签，Illustrative example，可拖）+ 一行说明。源码顺序 H1 → 副题 → 回答 → 生成器 → 对比，与手机一致；手机上这张对比图就在生成器的取景框里，桌面只是把它抽出来放在旁边。768–1023 之间单列：文字最宽 640，生成器最宽 480，取景框里仍显示示意拼图。
- **首页其余区块（≥1024）**：每个 `.block` 两栏 `352px | 1fr`，H2 在左列吸顶（top 88），内容在右列；「一张手机照 → 一整套拍摄」三张成片一行三张、账单两栏；三步一行三列；模板按分类一行：分类标题左、卡片右（每行三张，单模板类目用 220px 媒体 + 文字 + Preview 幽灵胶囊）；免费说明三卡并排；内链两列；页脚两栏 + MiSans 署名行（只在营销页：首页、定价）。
- **浮动主按钮（dock）**：桌面右下角 320px 宽，不再全宽；规则不变（生成器离开视口才出现，页脚附近隐藏）。
- **Create**：精选视频卡 768 为 21:9、1024 为 24:9；分类 chips 换行、不横滚、吸顶在顶栏下（top 56）；模板网格 768 三列、1024 四列，行距 24 / 列距 16；Preview 胶囊是照片上的磨砂灰（`--photo-scrim`），不是实心按钮。
- **工作台（≥1024）两列**：`minmax(380px, 440px) | 1fr`，列间 48。左列：上传面板（空状态两个幽灵按钮并排）、补充说明、尺寸 8 项（四列两行）、清晰度三张、余额提示；**唯一主按钮吸底在左列末尾**（`position: sticky; bottom: 0`，上方 16px 渐隐），不再是全宽固定底栏。右列「显影盘」`.stage` 吸顶（top 72）：4:5，宽度 `min(100%, (100dvh − 220px) × 0.8)` 保证整张在视口内；五个状态换内容——empty 显示模板示意拼图（Phone / AI）；ready 显示用户原图 + 「Your photo」「4:5 · as shot」；generating 灰阶负片 + 安全灯扫描线显影（页面唯一动效）；done 成片 + 「Done」；failed 灰阶负片 + 「Not developed」。
- **工作台新增状态（手机也有）**：`?state=done`（左列「Saved to Photos」+ 「Make another」链接，主按钮手机 Share / 桌面 Download）和 `?state=failed`（左列 "Generation failed. Your credits were refunded." + 幽灵「Change photo」，主按钮 **Retry · N credits** 唯一）。手机上失败信息排在预览之上。
- **定价页 pricing.html（新）**：营销页壳，375 响应。H1「Pay monthly, pay yearly, or buy credits once」；Monthly / Yearly 分段控件 ≥768 为 280px；三档卡 ≥768 并排三栏等高（Starter 石墨 / Pro 蓝宝石玻璃 / Max 黑金，与付费墙同一份 `css/tiers.css` + `js/tiers.js`），每张卡底部一个按钮：**只有 Pro 的「Choose Pro」是实心主按钮**，Starter / Max 是幽灵按钮（Max 的字是金色）；积分包一行三项各带幽灵「Buy」；下方两栏：「What a credit buys」(Standard 2 / HD 4 / Max 6) 和「Pay with」（Card · Apple Pay · Google Pay / Alipay，不带中文）。只有年付显示节省，月付不显示任何节省字样。页脚加 MiSans 署名。
- **付费墙对话框**：920px 宽；标题 + 说明在左、Monthly / Yearly 在右同一行；三档一行三栏等高（约 280px 一张）；积分包三项；付款方式两列；结账条固定在对话框底部，左细则、右主按钮（最小 320px）。背后工作台只变暗（brightness .45），不缩放。内容、权益、Coming soon 分组、Alipay 文案与手机抽屉一字不差。
- **Photos**：进行中任务两列；完成作品 768 三列、1024 四列；扫描线只在 `data-job="generating"` 的任务上动，`queued` 不动。
- **通用**：输入框 16px 不变；所有可点区域 ≥44px；1280 / 1440 整页无横向滚动（实测）；文案留了 30% 的中文余量（标题 `text-wrap: balance`，段落 `text-wrap: pretty`，没有固定宽度的文字盒）。

## 与规范的差异（总控定，稿子未按规范改）

- **桌面 H1 字号**：稿子里首页 / 定价页 H1 在 ≥768 为 36px（Title 刻度，手机 32px），规范 §3.2 写的是「桌面 48px」。48 不在暗房的衬线刻度（52 / 40 / 36 / 32）上，三栏首屏里 48px 也会把 H1 挤成四行；要么规范改成 36（或 40），要么稿子加一档。
- **应用页内容最宽**：稿子用 1120px（Create / Photos 网格 3–4 列、工作台两列都需要），规范 §8.6 写的是 720px 居中。
- **顶栏链接**：稿子是四个链接（Create / Wishlist / Photos / Account，Wishlist 跟随 `features.wishlist`）左对齐，规范 §8.6 写的是「顶栏右侧三个链接」。三个 / 四个随开关；左对齐是因为右侧已经留给余额胶囊和返回栏的对称。
- **工作台两列以外的桌面专属布局**：规范 §8.6 只允许工作台两列；稿子里首页首屏三栏、Create / Photos 多列网格、付费墙三档并排也是桌面才有的布局（都只是密度，不是功能或入口）。
- **主按钮位置**：规范写「底部主操作栏变成内容区末尾的大按钮」，稿子是吸底在左列末尾（sticky），滚到底就是内容末尾。
