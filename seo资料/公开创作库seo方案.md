# Shotviva 用户作品公开展示页规格 v1

本文是 Shotviva建站规格v2.md 第 2 节 R6（索引管理）的细化，追加执行。
冲突时：本文管 UGC 页面，Shotviva建站规格v2.md 管其他页面，其余规则不变。

## 0. 三句话
1. 作品页一律 `noindex, follow`，不参与排名。
2. 拿来排名的只有标签聚合页，且必须先核实搜索量、再建页。
3. 上线前 8 周不开公开展示；开时第一批 10~20 个标签页，之后每周 +3~5 个。

## 1. 三类页面（各干一件事，不许混）

| 路径 | 示例 | robots | sitemap | 职责 |
|---|---|---|---|---|
| /g/[id] | /g/7f3a9c | noindex, follow | 不放 | 给用户看 + 分享 |
| /tag/[slug] | /tag/grilled-salmon | index, follow | 放 | 争排名、承接搜索 |
| /gallery | /gallery?page=2 | index, follow | 放 | 给爬虫入口、社交证明 |

## 2. 硬规则

### U1 标记写法：noindex, follow。永远不要 nofollow。
- noindex = 不收录；nofollow = 不传递链接价值。两者作用不同，不能互换。
- follow 必须保留：作品页上指向标签页、工具页的链接靠它把权重传回去。
- 实现二选一或都写：`<meta name="robots" content="noindex, follow">`
  或响应头 `X-Robots-Tag: noindex, follow`（后者对图片、PDF 也生效）。

### U2 绝对不要用 robots.txt 屏蔽 /g/。
被 robots.txt 挡住，爬虫根本读不到 noindex，页面会长期以
「已发现 - 尚未编入索引」挂在 GSC 里，你既控制不了、也拿不到 follow 传权重的收益。

### U3 作品页必须 200、公开可访问、无遮罩。
不许「登录才能看」、不许「下载前弹窗盖住整页」。爬虫读不到内容，
noindex 依法生效但用户体验和分享链路同时废掉。

### U4 作品页不进 sitemap。
sitemap 只含：pages / templates / tags / gallery / blog。

### U5 作品页 URL 用不可枚举 ID。
UUID 或 nanoid，例如 /g/7f3a9c81。
禁止用提示词或关键词做 slug（/g/yellow-dog）：会形成几万个近似 URL，
还会和标签页抢同一个词。这条最容易在开发阶段被省掉，务必写进需求。

### U6 标签页白名单：有搜索量才建。
- 每个标签页必须有唯一主词，且该词已核实过月搜索量（工具：搜索量核实 / 难度）。
- 没量的标签只在站内做筛选、前端过滤，不生成独立 URL。
- 起步 10~20 个，不许一次建 100 个以上。

### U7 标签页必须做厚（五项，缺一不算完成）。
1. 顶部直答块 40~60 词，以主词开头（承接 Shotviva建站规格v2.md 的 G1）
2. 围绕主词 150~300 词文案：这个场景怎么出图、参数和注意点
3. 作品网格 6~24 张，alt 写「场景 + 主体 + 光线」
4. 生成入口（表单或 CTA 按钮）
5. 相关标签 5~10 个（横向内链）
- 主词密度：参考 crazygames 的 /t/ 页——核心关键词是全页出现频率最高的词
  （car games 出现 17 次）。你控制在 Title/H1/H2/正文/alt 自然出现 10~20 次，不许堆。

### U8 同词冲突处理。
作品页的提示词如果正好命中站内已有的标签页主词或工具页主词：
作品页保持 noindex，页面上的链接直接指向那个标签页，并给出「查看同类作品」入口。
禁止为它生成一个和标签页同名的 slug。

### U9 数量与时间闸门。

| 阶段 | 时间 | 公开作品页 | 标签页 | 前提 |
|---|---|---|---|---|
| 第 1 期 | 上线 ~ 第 8 周 | 0（功能不开） | 0 | 首页 + 模板 + 工具 + 内页 |
| 第 2 期 | 第 8 ~ 12 周 | 开（全部 noindex） | 10~20 | GSC 里已有页面拿到曝光和点击 |
| 第 3 期 | 第 12 周起 | 照常 | 每周 +3~5 | 已编入索引数在稳定增长 |

### U10 停止线（硬性，触发就停手）。
- 「已抓取 - 尚未编入索引」连续两周上涨 → 停止新增页面，回头做厚已有页
- 「已编入索引」的页面数不再增长 → 同上
- 任何一周新增标签页超过 5 个 → 违规，退回上一阶段
- 停下来时做什么：加文案、加作品、加事实块、加内链，不加新 URL。

### U11 控制抓取预算。
- 作品页只能从 /gallery 的当前页、以及标签页的作品网格链到。
- 禁止「最新作品无限滚动 + 无上限翻页」这种把几万页全挂上内链的做法。
- /gallery 分页最多 20 页（约 480 张）；更早的作品只在标签页里出现。

### U12 结构化数据与分享。
- 作品页：不加 ImageObject / Article 结构化数据（noindex 页加了没意义）。
  只加 og:image、twitter:card=summary_large_image，保证分享有图。
- 标签页：ImageGallery 或 CollectionPage + BreadcrumbList。
- 所有页面 canonical 一律指向自己（作品页也要写，别省）。
- 分享链接用公开 URL，不带 token、不带会话参数。

## 3. 开发交付要求（约束，不是实现方案）

- 路由三条：/g/[id]、/tag/[slug]、/gallery
- 数据表以 规范/ARCHITECTURE.md §9 为准（不另建 ugc_works，公开作品即 generation_jobs 中 visibility = public 的记录）。原设计 ugc_works：id(uuid) / image_url / prompt / tags[] / created_at /
  is_public(默认 false) / indexable(默认 false)
- 只有 is_public = true 的作品才生成页面；默认 closed
- 渲染：SSG / ISR，源码可见正文（同 Shotviva建站规格v2.md R5）
- 审核未通过或已下架的作品：返回 404，不要返回 200 + noindex
- noindex 由全局配置统一控制，禁止逐页手改（手工改必然漏）
- 内链规则：/gallery → 标签页 → 工具页；作品页只入不铺（不向外大量铺链接）

## 4. 验收清单（逐条上线前勾）
- [ ] 打开任意作品页 Ctrl+U，源码里有 `noindex, follow`
- [ ] 响应头里没有 `nofollow`
- [ ] robots.txt 没有 Disallow: /g/ 或 Disallow: /tag/
- [ ] sitemap.xml 里 grep 不到 /g/
- [ ] 作品页 URL 是随机 ID，不是关键词
- [ ] 每个标签页都有：直答块 / 150 词以上文案 / 作品网格 / 生成入口 / 相关标签
- [ ] 每个标签页的主词都核实过搜索量，有一份词表存档
- [ ] 标签页之间至少有 5 条横向内链
- [ ] 作品页分享到微信 / X 能正确显示图片与标题

## 5. 上线后每周一检查（三项）
1. GSC「已编入索引」页面数：涨 / 平 / 跌
2. GSC「已抓取 - 尚未编入索引」页面数：涨 → 触发 U10 停止线
3. 标签页的曝光与点击：有没有单个词开始进前 50

判定：连续 4 周标签页零曝光 → 检查词选错还是页面太薄，先改页面不加页面。
