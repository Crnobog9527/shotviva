# 新积分目录的模板上架规则

## 当前可启用的模板

目录切换时保留各模板原有的启用状态与展示渠道。预扣按分辨率读取模板的实际价格，作品编辑从成品页进入，伙伴自由生成使用 1K 报价。

|用途|模板 ID|目标模型和质量|1K / 2K / 3K 新积分|
|---|---|---|---|
|菜品|dark-dining、delivery-menu|GPT Image 2.6 Sunburst，medium|74 / 150 / 225|
|产品|white-background、lifestyle-table、spa-podium|同上|74 / 150 / 225|
|普通海报、宠物、伙伴自由生成|promo-poster、pet-studio、freeform|同上|45 / 120 / 190|
|作品编辑|edit|同上，含修改范围判断|20 / 37 / 58|

上表只有在新单位和对应目录激活后才生效。后台显示模型的成本建议。只有指定模板、已核对的供应商与模型、质量和该档的精确价格符合批准记录，才能按批准价例外保存。已有模型配置变动需重新核验成本和支持的输入。

## 已定价格、尚未上架的用途

|用途|已定价格|上架前操作|
|---|---|---|
|精细文字海报|high，1K 120 / 2K 240 / 3K 360|先在后台创建独立草稿模板，在官方 GPT Image 2.6 Sunburst 上用 high 逐档核对文字、输出尺寸和成本，明确独立模板 ID 和展示渠道。通过后将 ID、模型、high 和三档精确价加入受审的目录绑定。普通海报 promo-poster 继续使用 medium 与自己的价格。|
|画风迁移|目标 medium，1K 20；2K、3K 未定|先选定便宜模型，验证参考图、分辨率、质量、成图和费用，再为批准的画风模板 ID 发布目录更新，只开放已确定的档位。1K 原始成本 $0.019 是测算预算。现行模板要求保存三个整数价格，因此只开放 1K 时必须同时按实测能力限制可选分辨率和服务端预扣，绝不能把未定档位填写成临时可售价格。|

这两行只用于内部筹备。公开价格页、模板库、伙伴目录和工作台均以实际可用模板为准。新增价格例外走目录变更审查，并用真实数据库核对模型路由、公开报价、预扣、原池退回与重复请求。运营配置不应自行打开现有画风模板或用 GPT 替代未选定的画风模型。

## 下架和预览测试模板

切换会下架 bright-listing、evening-glow 和所有当前在售的 art-styles 模板，同时取消其精选位置。切换时仍活跃且 ID 以 qa- 开头的模板视为测试专用，同样下架并保留原状态快照。其他未映射的活跃模板会中止整次切换，错误中列出 ID。

2026-11-09 的预览库有 7 个活跃模板，其中 qa-t61-a、qa-t61-b、qa-t61-c、qa-t61-d、qa-white-bg 共 5 个在切换时下架，另两个是 edit 和仅伙伴可用的 freeform。另有 6 个 qa- 草稿在审计时已经停用。已被切换下架的条目受数据库保护，常规编辑、批量或导入不能直接将它们重新发布。原先已停用的非画风 QA 草稿仍维持原状态，未写入本次下架快照。部署前按当天的实际清单复核。

激活入口仅供数据库总切换事务调用。该事务先取得公共锁、完成钱包步骤、写入 v2 标志，再调用 admin.activate_template_price_catalog_v2()，最后统一提交。回滚调用 admin.rollback_template_price_catalog_v2() 并在同一事务末尾还原标志。模板已被运营改动或已产生新目录预扣时，停止自动回滚。激活或回滚后刷新模板与供应商缓存，并分别核对工作台、作品编辑和伙伴模板列表。
